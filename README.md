# Pikapp Neighborhood Delivery

En base a la identidad de marca que te brindo, vas a desarrollar un sitio web full responsive para Pikapp con las siguientes secciones:
1. Navbar = Logo en la izquierda, items centrado, en la derecha redes sociales. El menú hamburguesa que tenga una animación de costado que cuando abra ocupe toda la visual de la pantalla. 
2. Hero = El hero debe decir algo como "Repartí sin regalarle tu negocio a nadie". Un texto debajo como "sin comisiones extras blabla.." un poco de sarasa ahí. 
3. Una sección con distintos rubros, Gastronomía, Farmacias, Almacenes. 
4. Una seccion con un paso a paso con scroll driven para animar (te dejo referencia). Que sean 4 pasos. 1. Selecciona local, suma producto al carrito, elegí delivery o retirar, paga con mercado pago.
5. marcas que confian. Haría un breve zócalo con logos de marcas en carrusel en movimiento continuo, leve movimiento. En los costados agregaría un difuminado.
6. Preguntas FAQ.  4-5 preguntas no más.
7. Formulario y CTAs a descarga de aplicación según android o apple. 
8. footer

Debe predominar el naranja, el marron oscuro #200f07 y el #FFF9EB. El glassmorfismo es importante también.  como el blurreado, degradado. etc. 

Utiliza INTER como tipografia, book textos y bold para titulos
